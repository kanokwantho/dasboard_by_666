# AI Task Handoff: Thailand Internship Dataset Interactive Dashboard Generator

## Task Overview
Transform the provided dataset of Thailand Internship Statistics (covering 1,250 companies across 20 job categories) into a single-file, fully interactive, and responsive web dashboard in HTML5 format.

## Technical Specifications
1. **Tech Stack Requirements**:
   - Single-file HTML5 with inline CSS (Tailwind CSS via CDN) and JS.
   - Chart.js (via CDN) for dynamic data visualization.
   - DataTables or vanilla JS for interactive data grid manipulation.
2. **Key Interactive Features**:
   - **Global Search & Filter**: Instant filtering by job category, work format (On-site/Hybrid/Remote), location, and salary/stipend range.
   - **Interactive Charts**:
     - Bar Chart / Donut Chart: Job Field Distribution (Ranked 1 to 20).
     - Scatter Plot / Grouped Bar: Average Stipend comparison vs. Work Format ratio.
   - **Editable Data Grid (ContentEditable / Inline Edit)**:
     - Users must be able to directly edit cell values (e.g., positions, stipend range, required skills) in the table.
     - Live recalculation: Chart data and summary metrics (Total positions, Average stipend) must automatically update whenever a user edits a table cell.
   - **Data Export Options**:
     - Export to CSV button.
     - Export modified data to JSON button.
